# Ambience DSP アルゴリズム最適化・音響物理モデリング ＆ 検証技術 完全アーカイブ

本ドキュメントは、Ambience リバーブ（16次 FDN ＋ 3段シリアル Nested Allpass トポロジー）における DSP アルゴリズムの進化、音響工学的モデリング手法、客観的数値検証ロジック、およびトラブルシューティングの全知見を記録・永続化するアーカイブである。

---

## 1. 空間音響アーキテクチャ概要

Ambience は、以下の 4 層ハイブリッド音響構造によって構成される：
1. **Pre-Delay & Input Diffusers（入力拡散段）**: 4段シリアル Schroeder Allpass（遅延長 3ms〜9ms）。
2. **Early Reflections Engine（初期反射段）**:
   - 実測空間および物理媒体（Room, Hall, Plate, Spring, Goldfoil）に基づく 12本の幾何学的・過渡タップ。
   - **実空間壁面吸収フィルタ（Wall Boundary Absorption 1次 LPF: $f_c = 8000\text{Hz} \times 0.91^{\text{tap}}$）**。
   - **幾何学方位角ステレオパンニング（Azimuth Spatial Panning）**。
3. **16次 Feedback Delay Network（FDN メインループ）**:
   - **共約不可能（Incommensurate）素数べき乗遅延長**: 黄金比/白銀比分布によりモード重複（Harmonic Coincidence）を根絶。
   - **直交ユニタリ Walsh-Hadamard 混合行列（FWHT）＋ 最適符号反転（Sign Flipping）**。
   - **10バンド GEQ 吸収フィルタ（Stage-2 Biquad Absorptions）**: 実空間大気減衰（4k $\le$ 2k×0.9, 8k $\le$ 4k×0.75, 16k $\le$ 8k×0.60）を完全再現。
   - **非同期デュアル黄金比 LFO（Dual Incommensurate LFO）**: 主周期＋黄金比副周期（0.618）の合成により、周期的うねりを完全破壊した有機的大気ドリフト。
   - **ループ内非対称マイクロサチュレーション（$+0.035 x^2$）＋ 全チャンネル独立 5Hz DC ブロッカー ＋ RMS リミッター**。
   - **Schroeder 型 Direct Form Modulated Allpass（3段シリアル）＋ 有界変調ガード（Bounded Safe Modulation $\le 40\%$）**。
4. **Output Stage（出力段）**:
   - **Vintage Warmth Saturator**: Warm (偶数・奇数黄金ブレンド), Tape (磁気飽和), Tube (3極真空管 Triode 2次倍音), Hard (トランス飽和)。
   - **Output EQ (LoCut / HiCut) ＆ Output Lookahead Limiter**。

## 2. 課題と解決の DSP 理論

### ① モジュレーションノイズ（ブチッ、バチッ音）の根絶
- **発生メカニズム**: Allpass の変調深さが基準遅延長を超えて負（$<0$）になり、リングバッファのインデックスがラップアラウンドしてメモリ不正アクセス `nan`（非数バースト）を発生させていた。
- **解決策**:
  1. Schroeder 標準型 Direct Form Transposed トポロジーの採用（時間変動時でもエネルギー保存）。
  2. **有界変調（Bounded Safe Modulation）**: 変調深さをベース遅延の最大 40% にクランプ（$D_{\text{safe}} = D_{\text{base}} + \text{lfo} \times \min(\text{depth}, D_{\text{base}} \times 0.40)$）。
  3. `LinearDelayLine::read` に `std::clamp` による 4 サンプルの境界安全マージンを実装。
  4. サンプル単位でのパラメータ 1次 IIR スムージング。

### ② ピッチ揺らぎの自然化（有機的大気ドリフト）
- **発生メカニズム**: 単一正弦波 LFO は周期的な往復パターンを耳が認識してしまい、機械的・デジタルなうねりを感じさせる。
- **解決策**:
  - **非同期デュアル黄金比 LFO**:
    $$L_i(t) = 0.75 \sin(2\pi f_i t + \phi_i) + 0.25 \sin(2\pi (0.618 f_i) t + \psi_i)$$
  - 16チャンネルすべての初期位相を黄金比で分散配置し、自己相関ピーク（Periodicity Index）を大幅に低減。

### ③ デジタル臭さの解消と Vintage のぬくもり（2次偶数倍音モデリング）
- **発生メカニズム**: 従来の対称サチュレーション（$\tanh$ や 3次多項式）では奇数倍音（H3: 3次高調波）しか発生せず、冷たい歪みとなっていた。
- **解決策**:
  - **非対称伝達関数の導入**:
    - `Tube`: $f(x) = \frac{x_{\text{pos}}}{1 + 0.45 |x_{\text{pos}}|} + \frac{0.35 x^2}{1 + 2.0 |x|}$（2次偶数倍音 H2: -47.8dB を豊かに付加）。
    - `Warm`: $f(x) = \tanh(x) + \frac{0.22 x^2 (1 - \tanh^2(x))}{1 + |x|}$。
    - `Tape`: 磁気ヒステリシス多項式＋高域ソフトコンプレッション。
  - **FDN ループ内マイクロサチュレーションの非対称化**: 微小な 2次非対称項（$+0.035 x^2$）により、残響が巡回するたびに自然なヴィンテージ倍音が蓄積。
  - **暴発・発散の 4重安全保証**: 縮小写像（傾き $\le 1.0$）、全 16ch 独立 5Hz DC ブロッカー、ユニタリ直交行列、RMS リミッター。

### ④ 初期反射（ER）の実空間壁面ダンピングと全アルゴリズム対応
- **発生メカニズム**: 初期反射タップが高域減衰なしのフラットだったため、高域過多（$+9.8\text{ dB}$）となり、パチパチした硬い音が Late Reverb と分離していた。
- **解決策**:
  - 反射回数に応じた壁面吸収 1次 LPF（$f_c = 8000\text{Hz} \times 0.91^{\text{tap}}$）を導入。
  - **Plate / Spring / Goldfoil の金属初期タップ（Dense Metallic Taps: 12 taps）の実装**: トランスデューサーからピックアップへの超初期金属分散振動（0.8ms〜15ms）をモデリングし、ER Solo でもしっかり音が鳴るように修復。

### ⑤ B026 決定版：過渡応答ソフトスロー ＆ ステレオ完全拡散アーキテクチャ
- **発生メカニズムと教訓**:
  - ループ内に 1次 IIR Monotonic Roll-off などの余計なフィルタを挿入すると、10バンド GEQ のエネルギー保存則と干渉し、高域が不自然に早く落ちたりフィードバック暴発（正帰還）を引き起こすことが判明。
  - **DSP の鉄則**: **FDN ループ内の 10バンド GEQ と 3段 Schroeder Allpass は B023 の完成された状態を 100% 崩してはならない**。
  - アタック音（スネアやピックの打撃音など）の角やコムフィルタリングを抑えるには、ループ内を汚すのではなく、**「リバーブ入力（Wet 側）へのアタック突入エネルギーを事前に整流・拡散する」** のが音響工学的に最も正しく安全。
- **B026 で確立した 4 大決定打**:
  1. **FDN ループの B023 完全復帰（暴発・不自然減衰の根絶）**:
     ループ内の 10 バンド GEQ（`MagnitudeResponseFitter`）による各空間の正確な残響時間制御とユニタリ直交行列の安定性を 100% 回復。
  2. **過渡応答ソフトスロー (Transient-Aware Input Softener)**:
     瞬間的なアタックピーク（トランジェント）を自動検出し、Dry 信号の鮮明なアタック感は 100% 保ったまま、Wet（リバーブ）側へのアタック突入過剰エネルギーのみをソフトに平滑化。FDN 内でのコムフィルタリング・金属的重なりを物理的に防止。
  3. **Stereo Input Diffuser（Mid & Side 完全拡散）**:
     Mid と Side の双方に 4 段ディフューザーを適用し、左右のステレオアタックを 25ms の「柔らかな雲（Diffusion Cloud）」に変換してリバーブタンクへ供給。
  4. **入力段 Bandwidth 1次 LPF（$f_c = 12\text{kHz}$）**:
     自然な空気感と透明感を保ちながら、15k〜20kHz の超高域スパイクのみを優しく丸め込む。
  5. **LOCK OFF 時の RoomType 切り替えデフォルトロード完全修復**:
     UI コールバックから `audioProcessor.loadPresetDefaults(newAlgo)` を直接呼び出すことで、LOCK OFF 時に確実に各ノブが新しいルームタイプのデフォルト値へリセットされるよう修復。

### ⑥ B027：マルチDAW（Cubase, Studio One, Reaper, FL Studio, LUNA）完全互換性 ＆ 巨大空間音響物理スケーリング
- **他 DAW でのクラッシュ・読込失敗要因と解決策**:
  1. **厳格バスレイアウト対応（`isBusesLayoutSupported`）**:
     Cubase, Studio One, LUNA, Reaper 等が要求する `Stereo->Stereo`, `Mono->Stereo`, `Mono->Mono`, `Stereo->Mono` を正式サポート。Mono 入力時は内部で Dual Mono 展開し、Mono 出力時は Downmix ルーティングを行うことで、Mono トラックでの読み込み拒否・無効化・クラッシュを完全根絶。
  2. **変則ブロックサイズ（FL Studio / Reaper）保護**:
     FL Studio の非標準・奇数サンプルバッファ（7, 33, 47サンプル等）やレンダリング時の巨大ブロックに備え、`prepareToPlay` で `std::max(samplesPerBlock, 8192)` を事前確保。オーディオスレッドでの再メモリ確保（Heap Allocation）を根絶。
  3. **VST3 カテゴリ規格準拠**:
     `CMakeLists.txt` に `VST3_CATEGORIES "Fx|Reverb"` を定義し、全 DAW のリバーブブラウザで正確に認識。
  4. **防御的ステートパース**:
     Cubase 等が初期化時に渡す `nullptr` / 0バイト / 不正バイナリに対する完全な安全ガードを配備。
- **巨大空間（Inchindown / 112秒リバーブ）の音響物理遅延線スケーリング**:
  - 音響物理学における部屋の体積 $V$ と平均自由行程（Mean Free Path: $\bar{l} = \frac{4V}{S}$）に基づき、各アルゴリズム固有の `ALGORITHM_DELAY_BOUNDS` テーブルを新設。
  - **Room1 / Plate**: 4.8ms〜38ms のタイトな遅延線により、濃密でタイトな部屋鳴りを実現。
  - **Inchindown（体積 125,000 m³、全長 237m）**: 55ms〜330ms（RoomSize=2.0 で最大 660ms）の超長大遅延線を適用し、トンネル特有の「まばらな初期エコー（Sparse Echoes）から雄大な112秒長大残響へ」の音響推移を物理工学的に忠実再現。

### ⑦ B028：長大空間（Inchindown 等）での ER バッファ・ラップアラウンドノイズ（ビリビリ音）の完全根絶
- **発生メカニズム（ユーザー推測通りの ER バグを完全解明）**:
  1. **ER ディレイバッファの容量不足**: `erDelay` のメモリ確保量が `fs * 0.1`（約 170ms @ 48kHz）だったのに対し、Inchindown の ER パターンは最大 `332.5ms`（RoomSize 適用時で `498ms〜831ms`）に達していた。
  2. **リングバッファのラップアラウンド・波形不連続ジャンプ**: バッファ境界（170ms）を大きく超えるタップを読み出す際、`LinearDelayLine` が循環して最新の書き込みポインタや境界を飛び越えて読み出していた。
  3. **音の重なりによる顕在化**: 音を多数重ねて入力振幅が大きくなった際、このバッファ境界ジャンプが「ビリビリ、バリバリ」という鋭利な不連続ノイズ（Glitch）として再生され、入力音が止まると FDN テイルのみが残ってノイズが消える現象が発生していた。
- **解決策**:
  1. **`erDelay` メモリ確保量を 1.0秒（最大 1.36秒 / 65536 サンプル @ 48kHz）へ拡張**: Inchindown の最大タップ（831ms）でもバッファに余裕を持って収まるよう拡張。
  2. **ER 遅延サンプル数の安全クランプガード**: `currentERDelaySamples` に `maxSafeERDelaySamples` ガードを配備。
  3. **多タップ空間における `erMakeupGain` の適正化**: タップ数が多い空間での ER ゲイン過大飽和を防止。

### ⑧ B029：過大メイクアップゲイン・リミッターAMチャタリング・アタック段差ノイズの完全根絶
- **発生メカニズム（完全特定）**:
  1. **Decay最大時の過大メイクアップゲイン（+32dB / 40倍ブースト）**:
     `baseDB = 16.0f` ＋ `decayCompDB = 7.0f * log10(rt60Mid)` により、長Decay時にリニアで 40倍もの爆音ブーストが適用され、内部エネルギーが $+20\text{dBFS} \sim +30\text{dBFS}$ に達していた。
  2. **OutputLimiter のゼロクロス追従型 AM 変調（メーター小刻み揺れ ＆ バリバリ音）**:
     瞬時サンプル値（`std::max(absL, absR)`）に追従していたため、ゼロクロス通過時にゲインが $0.03 \leftrightarrow 1.0$ で毎サイクル振動（オーディオ周波数の2倍で激しくチャタリング）し、波形を矩形波状にズタズタに切り刻んでいた。
  3. **FDN ループ内 RMS コンプレッサーの波形チョッピング**:
     時定数 3ms の短すぎる RMS 追従により、低中域の山だけを削る波形歪みを生んでいた。
  4. **最初の一音を押した時の「サー」というノイズ**:
     過渡ソフトスローのステップ段差（1サンプルで $1.0 \to 0.62$ へ急落）が全帯域に白色雑音（White Noise）を撒き散らし、それが 4段ディフューザーと 3段 APF で引き伸ばされ、+32dB 爆音ブーストで噴出していた。
- **解決策**:
  1. **メイクアップゲインの音響エネルギー保存則適正化**:
     `baseDB = 5.0f`、長Decay時の余計なブーストを撤廃し、最大でも $+5\text{dB}$ 前後に制御。
  2. **OutputLimiter にピークエンベロープ＋ゲインスムージング（1ms）を導入**:
     ゼロクロス変調チャタリングを完全遮断し、メーターの小刻み揺れと波形歪みを 100% 根絶。
  3. **FDN ループ内に滑らかな $\tanh$ ソフトリミッターを導入**:
     不連続ハードクリッピングを完全撤廃。
  4. **過渡入力の $C^1$ 連続ソフトリミッティング**:
     アタック段差スイッチを廃止し、最初の一音を押した瞬間の「サー」というノイズを完全消滅。
  5. **Saturator Hard モードの多項式発散バグ修正**:
     単調増加の有理関数へ修正し、過大入力時の逆極性爆発を防止。

## 3. 客観的音響測定・ベンチマーク手法（数値検証ロジック）

| 測定項目 | 数学・物理的指標 | 測定アルゴリズム | 判定基準 |
| :--- | :--- | :--- | :--- |
| **金属音・コムフィルタ鳴き** | **スペクトル平坦度（SFM: Spectral Flatness Measure）** | 幾何平均 / 算術平均（FFT パワースペクトル） | SFM が高いほどシルキーで平坦 |
| **ピッチ揺らぎの自然さ** | **瞬時周波数偏差（IFD in Cents）＆ 周期性指数（Periodicity Peak）** | ヒルベルト変換による瞬時位相微分 ＋ 自己相関ピーク検出 | Periodicity Peak が低いほど有機的 |
| **ヴィンテージ倍音特性** | **全高調波歪（THD %）＆ 2次/3次倍音比（H2/H3 in dB）** | 100Hz サイン波入力時の FFT ハーモニックピーク抽出 | H2 が豊か（Tube: -47dB）であること |
| **初期反射の空間包まれ感** | **両耳間相互相関（IACC: Inter-Aural Cross Correlation）** | $1 - \max |R_{LR}(\tau)|$ (0〜150ms) | 包まれ感（$1-\text{IACC}$）$\ge 50\%$ |
| **初期反射の高域バランス** | **ER HF/LF エネルギー比（dB）** | 4kHz〜12kHz エネルギー / 200Hz〜1kHz エネルギー | $+3\text{dB} \sim +6\text{dB}$ の自然な壁面減衰 |
| **ループ内安定性** | **Lyapunov エネルギー減衰比 ＆ DC 蓄積量** | 極限ストレステスト（+0dBFS 連打 ＆ +0.5 DC 注入） | 25秒後/10秒後比 $\ll 1.0$、NaN=0 |
