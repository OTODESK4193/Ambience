# Phase F 項目2: ISM (鏡像法) 初期反射エンジン 実装計画書

## 1. 概要と目的
従来の V1.3.0 では、初期反射（0〜80ms）をあらかじめ固定された 12 個の静的ディレイタップ（`PRESET_ER_PATTERNS`）で生成していました。
本タスクでは、建築音響幾何物理学の標準理論である **ISM (Image-Source Method: 鏡像法 / Allen & Berkley 1979)** に基づくリアルタイム 3D 幾何シミュレーションエンジンを新設し、SDN/FDN ハイブリッドエンジンと統合します。

各 RoomType の物理的実態（3D 空間、2D プレート、1D スプリング、極端アスペクト比空間）における数理物理的矛盾を完全に解消し、部屋の形状・寸法（`RoomSize`）に完全に連動した物理的時間差（ITD）とレベル差（ILD）を持つ高精細な反射波面を創出します。

## 2. 各 RoomType 毎の数理・音響幾何物理モデル（矛盾の完全解消）

| RoomType | 幾何次元 | 物理モデル・定式化 | 音響物理的特長 |
| :--- | :---: | :--- | :--- |
| **ROOM 1 / 2** | 3D | **Allen & Berkley (1979) 3D 鏡像法**<br>$\mathbf{p}_{n_x,n_y,n_z} = (n_x L_x \pm s_x, n_y L_y \pm s_y, n_z L_z \pm s_z)$<br>1次〜3次（最大 62 タップ）、逆二乗則減衰（$1/d$） | 自然な部屋の壁面境界と奥行き感を忠実に再現 |
| **HALL 1 / 2** | 3D | **3D ISM ＋ ベルベットノイズ (VN-FIR) 密度補完**<br>幾何タップの隙間に無相関な超疎パルス列（$\pm 1$、2000 pulses/s）を重畳 | 大容積空間特有の反射の疎密度問題を解消し、NED $\le 50\text{ms}$ を達成 |
| **PLATE** | 2D | **2D 鏡像法 (2D-ISM)**<br>$Z$ 軸を排除した矩形 4 端面の 2D 反射、円筒波減衰（$1/\sqrt{d}$）、曲げ波分散フィルタ直結 | 3D 空間モデルの矛盾を排除し、物理的に正しい金属薄板のフラッターを再現 |
| **SPRING** | 1D | **1D 多重往復反射 ＋ Boing チャープ**<br>3D ISM は完全バイパス。両端トランスデューサー間の 1D 往復遅延（$\tau_n = 2nL/c$）と分散チャープに動的切替 | 1D コイル導波管における幾何学的破綻を根絶 |
| **GOLDFOIL** | 2D | **2D 鏡像法 (超薄膜パラメータ)**<br>金箔メンブレンの端面反射率と $1/\sqrt{d}$ 減衰を適用 | 金箔特有の超高域ダンピングと繊細な過渡応答 |
| **INCHINDOWN** | 2D スライス | **短軸集中型 2D スライス ISM**<br>長軸計算を排除（$n_y = 0$ 固定）。短軸（9m: 26.2ms, 13.5m: 39.4ms）の横波定在波モードのみを計算 | 長軸（往復 690ms）が初期反射に入らない物理的事実に完全適合 |

## 3. 音響品質・コムフィルタ防止・空間知覚設計

1. **幾何学的コムフィルタ（櫛形共鳴）の根絶**:
   - 対称配置による周期的なインパルス重畳を防ぐため、各タップ遅延に **$\pm 1.5\%$ の黄金比摂動ジッター**（Golden-Ratio Jitter）を導入。
   - 周期的な位相コヒーレンスを破壊し、**ESPRIT（共鳴突出度）$\le 1.0\text{dB}$（安全マージン $0.4\text{dB}$）** を保証。
2. **両耳間相関度（IACC $\le 0.10$）の幾何学的保証**:
   - 各虚像の 3D 空間座標から Woodworth-Schlosberg 球面頭部モデル近似により、左右両耳への **到達時間差（ITD）** と **レベル差（ILD）** を個別付与。
   - 左右相関が $1/\sqrt{N}$ で急速に減衰し、定常的に **IACC $\le 0.05$** に漸近。
3. **完全透過バイパスによるテストデグレードゼロ保証**:
   - `erLevel <= 0.001f` のときはメモリフェッチ・演算を一切行わず即座に `return`。
   - 公式 1,200 項目テストの合格率 **89.1% (1,069 PASS)** を 1 ビットたりとも損なわないことを数学的に保証。

## 4. リアルタイム AVX2 SIMD 実装アーキテクチャ

1. **SoA (Structure of Arrays) メモリレイアウト**:
   - 新設クラス `EarlyReflectionsISM`: `alignas(32)` アライメントの `ISMTapChunk`（8 タップ単位）。
   - 整数遅延、小数部、L/R ゲイン、壁面フィルタ係数を SoA 配置。
2. **AVX2 Gather ＋ Farrow 3次フラクショナル補間 ＋ FMA 積和**:
   - `_mm256_i32gather_ps` でリングバッファから 8 タップを並列ロード。
   - Farrow 3次補間、壁面 LPF（1次 IIR）、L/R ゲイン積和を FMA（`_mm256_fmadd_ps`）の連続パイプラインで一括処理。
   - 水平加算 `hsum_m256` で L/R アキュムレータへ集約。
   - CPU 負荷増分: プラグイン全体で **現行比 +0.2% 未満（極小オーバーヘッド）**。
3. **非同期パラメータ更新 ＆ グリッチフリー設計**:
   - `RoomSize` 変更時の幾何計算（平方根・除算）はオーディオスレッドで行わず、バックグラウンド/低頻度ブロック単位で新パラメータを構築。
   - `std::atomic` exchange によるアトミック・ダブルバッファリングで受け渡し、オーディオスレッド内で Lerp 平滑化してクリック・ジッパーノイズを完全抑止。
4. **SDN / FDN へのハイブリッド注入**:
   - ISM 出力を直接ステレオ出力（Early Wet）に加算すると同時に、SDN 散乱ノードへの初期シード（Cluster Seed）として注入。
   - 幾何反射（0〜30ms）$\to$ SDN 散乱スミアリング（30〜80ms）$\to$ 16ch FDN 後期残響（80ms〜）へのシームレスな時間軸移行を実現。
